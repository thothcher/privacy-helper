Front-end rules

  • Unchecked by default. A pre-ticked box is not agreement.
  • Links that look like links. Underlined, high contrast, right beside the button.
  • Readable without leaving. Open the terms in a new tab or a modal and keep what the user typed.
  • Save proof. Send the terms version and a timestamp with the request.
  • Version everything. “Last updated” at the top; old versions at stable URLs like /terms/2025-11-10.
  • Explain, don't block. A real <label>, keyboard support and an inline error instead of a silent grey button.
  • Ask again on big changes. Show the new terms at next login and record a fresh acceptance.
// signup.js: an agreement that holds up in a dispute
form.addEventListener('submit', async (e) => {
  e.preventDefault();
  if (!agree.checked) {
    error.hidden = false;   // explain, don't just disable
    agree.focus();
    return;
  }
  await fetch('/api/signup', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      email: email.value,
      termsVersion: '2026-09-01',
      acceptedAt: new Date().toISOString(),
    }),
  });
});

    Front-end rules

    • Nothing before consent. Analytics and ad scripts wait for a clear “yes”.
    • Equal buttons. “Reject all” as easy to find and click as “Accept all”.
    • No pre-ticked boxes. One switch per purpose, all off by default.
    • Ask for less. Every form field needs a reason you could write in the policy.
    • Keep data out of URLs. No emails or IDs in query strings, logs or analytics events.
    • Honor signals and rights. Read Global Privacy Control; offer “Download my data” and “Delete account”.
    // consent.js: trackers wait for a clear yes
const consent = readConsent(); // { analytics: false, ads: false }
if (navigator.globalPrivacyControl) {
  consent.ads = false; // treat as "Do Not Sell or Share"
}
if (consent.analytics) loadScript('/js/analytics.js');
if (consent.ads) loadScript('/js/ads-pixel.js');

    § B.5 · Spot the fake

    Real site or fake site?

    Fake and careless sites give themselves away in their legal pages. Judge each exhibit, then use the toolkit on real sites.

    Exhibit 1 of 8Score 0

    All exhibits are fictional examples.

    Detective toolkit

    • SEARCH

      Copy one sentence from the policy and search it in quotes. Hundreds of hits under other brand names means a copied template.

    • REGISTRY

      Look the company up: Georgia's Public Registry (napr.gov.ge), EU business registers, US state registries. A real business is listed.

    • WHOIS

      Check the domain's age. A shop “trusted since 2009” on a domain registered last month is lying.

    • ARCHIVE

      Open the policy in the Wayback Machine (web.archive.org). Real companies have a history of versions.

    • DEVTOOLS

      Compare the policy with reality. Trackers in the Network tab that the policy never mentions are a broken promise.
